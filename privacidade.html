Política de privacidade

Atualizada em 11/11/2026.

Quem usa

O Life Cockpit é um app pessoal. Só o dono da conta Google autorizada usa e vê os dados.

Quais dados

Com a permissão do usuário, o app lê pela Google Health API, apenas para leitura: sono, frequência cardíaca, variabilidade da frequência cardíaca, respiração, temperatura, VO₂ máx, passos, minutos em zona e exercícios.

Como são usados

Os dados são baixados para o computador do próprio usuário e usados só para montar o painel pessoal dele. O app não vende, não compartilha, não usa para publicidade e não envia esses dados a terceiros.

O uso de dados recebidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.

Guarda e exclusão

Os dados ficam no computador do usuário. Ele pode apagá-los a qualquer momento e revogar o acesso em myaccount.google.com/permissions.
